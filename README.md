# QTAP: Quantum Torsion Angle Predictor

**Quantum Torsion Angle Predictor (QTAP)** is a novel hybrid quantum-classical framework that uses a variational quantum Born machine to predict backbone φ/ψ dihedral angle distributions from amino acid sequence embeddings. The quantum circuit encodes residue-level features into a parameterized ansatz, and measurement statistics define a probability distribution over Ramachandran space.

> **Author:** Tommaso R. Marena, Catholic University of America (CUA), 2026  
> **Status:** Research prototype — all quantum results are classically simulated via Qiskit Aer

---

## 🔬 What is QTAP?

Protein backbone conformation is largely determined by the φ (phi) and ψ (psi) dihedral angles of each residue. Predicting their distributions — not just point estimates — is critical for:

- Ensemble-aware structure prediction
- Loop modeling and flexible region analysis
- Intrinsically disordered protein (IDP) characterization
- Downstream docking and drug design

Classical approaches (e.g., neural networks trained on PDB statistics) produce sharp point predictions. **QTAP treats angle prediction as a Born machine sampling problem**: the quantum circuit's measurement outcome probabilities *are* the predicted Ramachandran distribution, naturally encoding uncertainty and multimodality.

## 🧠 Method Overview

```
Amino acid sequence
        │
        ▼
 Residue Embedding Layer  (one-hot + physicochemical features → 8D vector)
        │
        ▼
 Angle Encoding Circuit   (RY rotations on 4 qubits)
        │
        ▼
 Variational Ansatz       (alternating Ry/Rz + CNOT entanglers, depth d=3)
        │
        ▼
 Born Machine Sampling    (1024 shots → probability over 2^4 = 16 bins)
        │
        ▼
 Ramachandran Bin Mapping (16 bins → 4×4 grid over [-180°,180°]²)
        │
        ▼
 KL-divergence loss vs. PDB reference distributions
        │
        ▼
 COBYLA / ADAM optimizer  (classical outer loop)
```

## 📊 Key Results (Baseline)

| Metric | QTAP (4q, d=3) | Classical MLP baseline |
|--------|---------------|------------------------|
| KL divergence (test) | ~0.31 nats | ~0.28 nats |
| Ramachandran coverage | Multimodal ✅ | Unimodal ⚠️ |
| Parameters | 24 | 512 |
| Captures β-sheet region | Yes | Partial |
| Captures α-helix region | Yes | Yes |

> QTAP uses 24 variational parameters vs. 512 for a comparable MLP, while natively representing multimodal distributions — a key advantage for disordered residues.
