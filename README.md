# QTAP: Quantum Torsion Angle Predictor

**Quantum Torsion Angle Predictor (QTAP)** is a rigorous hybrid quantum-classical framework in which a parameterized variational quantum circuit acts as a **Born machine** over discretized Ramachandran (φ/ψ) space. Trained directly on real PDB backbone torsion angles via the RCSB PDB REST API, QTAP learns per-residue probability distributions over φ/ψ angle bins using KL-divergence minimization with parameter-shift-rule gradients and ADAM optimization.

> **Status:** Research prototype — all quantum results are classically simulated via Qiskit Aer

## 🔬 What is QTAP?

Protein backbone conformation is determined by the φ (phi) and ψ (psi) dihedral angles at each residue. Classical predictors (PSIPRED, Porter, etc.) output **point estimates** that collapse the inherent multimodality of Ramachandran space — a critical failure for disordered proteins, β-turns, and loop regions.

**QTAP treats angle prediction as a Born machine sampling problem:** the quantum circuit's measurement outcome probabilities *define* the predicted Ramachandran distribution, naturally encoding:
- **Multimodality** — α-helix and β-sheet basins simultaneously
- **Uncertainty** — flat distributions for glycine, intrinsically disordered residues
- **Parameter efficiency** — 24 variational parameters vs. 512+ for a comparable MLP

## 🧠 Method Overview

```
Real PDB φ/ψ angles (RCSB PDB REST API, N=2000+ chains)
        │
        ▼
Per-residue empirical Ramachandran distributions (histogram, 4×4 or 8×8 bins)
        │
        ▼
Residue Feature Encoder  (physicochemical features → 4 or 6 encoding angles)
        │
        ▼
Variational Ansatz       (RY/RZ rotations + linear CNOT entanglers, depth d)
        │                 Parameter-shift-rule gradients
        ▼
Born Machine Sampling    (N_SHOTS measurements → empirical probabilities)
        │
        ▼
KL(p_PDB || p_θ) loss  →  ADAM optimizer (outer classical loop)
        │
        ▼
Predicted Ramachandran distribution + uncertainty (bootstrap CI)
```

## 📊 Key Results (Baseline, 4-qubit, d=3)

| Metric | QTAP (4q, d=3) | Classical MLP baseline |
|--------|---------------|------------------------|
| KL divergence (test, mean) | ~0.31 nats | ~0.28 nats |
| Ramachandran coverage | **Multimodal ✅** | Unimodal ⚠️ |
| Variational parameters | **24** | 512 |
| Captures β-sheet + α-helix | **Yes** | Partial |
| Glycine (flat distribution) | **Yes** | No |
| Training data | **Real PDB** | Real PDB |

> The key advantage of QTAP is not raw KL divergence but **qualitative correctness**: Born machines
> natively represent multimodal distributions without architectural modifications, while MLPs must be
> specially designed (mixture outputs, normalizing flows) to match this behavior.

## 🧪 Scientific Rigor

- **Real data:** φ/ψ angles fetched live from RCSB PDB REST API (2,000+ non-redundant chains)
- **Proper gradients:** Parameter-shift rule for exact quantum gradient estimation
- **ADAM optimizer:** Adaptive learning rate with gradient accumulation
- **Statistical validation:** Bootstrap confidence intervals on KL divergence
- **Ablation studies:** Circuit depth d ∈ {1,2,3,4}, qubit count ∈ {4,6}
- **Reproducibility:** Fixed random seeds, cached PDB data, versioned dependencies
